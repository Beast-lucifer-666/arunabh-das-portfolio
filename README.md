# Arunabh Das — Developer Portfolio

A responsive React + Vite portfolio with Framer Motion animations.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

1. Create a new public repository named `arunabh-das-portfolio` (or another name).
2. Push this project to the repository's `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. The included workflow builds the Vite app and deploys it automatically.
6. Your site will be available at `https://Beast-lucifer-666.github.io/arunabh-das-portfolio/`.

The Vite config uses a relative base path so the site works from a GitHub Pages project URL.

## Personalization checklist

- Add a professional headshot if desired.
- Add a public professional email or LinkedIn URL when ready.
- Add a PDF resume to `public/` and link it from the site if desired.
- Verify every project description and technology list before using the site for applications.
